======================================================================
ASHFORD UNIVERSITY PORTAL - HOW TO RUN LOCALLY
======================================================================

WHAT YOU NEED
-------------
- XAMPP installed at C:\xampp
- The project folder: C:\Users\jimmy\Desktop\AshfordFun
- Nothing to install first. No Composer, no npm, no build step.


IMPORTANT: USE XAMPP'S PHP, NOT THE SYSTEM PHP
----------------------------------------------
Your system PHP has no MySQL driver, so the site cannot reach the
database with it. Every command below uses C:\xampp\php\php.exe
deliberately. Do not swap it for plain "php".


======================================================================
STEP 1 - START THE DATABASE
======================================================================

Option A - easiest, no typing:
  1. Open the XAMPP Control Panel.
  2. Click "Start" next to MySQL.
  3. Done. Your my.ini is already set to port 3300.

Option B - command line:
  Open PowerShell and run:

    C:\xampp\mysql\bin\mysqld.exe --datadir=C:\xampp\mysql\data --port=3300

  Leave this window open. That window IS the database. Closing it
  stops the database.

  Port 3300 is used because MySQL80 already holds port 3306 on this
  machine, and its root password is unknown to this project.

  Make sure .env has DB_PORT=3300 to match.


======================================================================
STEP 2 - START THE WEB SERVER
======================================================================

Open a SECOND PowerShell window (the first stays busy running the
database) and run this EXACT command, including router.php:

    C:\xampp\php\php.exe -S localhost:8000 -t C:\Users\jimmy\Desktop\AshfordFun router.php

Leave this window open too. It shows every request and any error.

The trailing "router.php" is load-bearing. It is what sends
http://localhost:8000/ to the public landing page. Without it,
"/" would land on the sign-in page instead.

Note the "-t" flag and the project path. Without them you will get
"not found" errors for every page.


======================================================================
STEP 3 - OPEN THE SITE
======================================================================

    http://localhost:8000

This opens the public landing page. The sign-in page stays at:

    http://localhost:8000/index.php

To stop the site, press Ctrl+C in both PowerShell windows.

======================================================================
TROUBLESHOOTING
======================================================================

"Database connection failed. Please check your MySQL settings."
   The database is not running, or .env points at the wrong port.
   Confirm: .env has DB_PORT=3300 and mysqld.exe is running.

You see raw PHP code, or the page is empty text
   You started the server with the system PHP. Rerun step 2 using
   C:\xampp\php\php.exe, which has the MySQL driver.

"/" shows the sign-in page instead of the landing page
   You left "router.php" off the end of the start command in step 2.

"Not Found" for every page, or a directory listing
   You left out the "-t" flag. Use the full command from step 2.

"Failed to listen on localhost:8000"
   Another program holds port 8000. Pick a different port, e.g.
     C:\xampp\php\php.exe -S localhost:8080 -t <project path> router.php
   then open http://localhost:8080

Sign-in always says "Invalid email or password"
   Use one of the real accounts above. ada.reyes / riley.chen /
   dana.whitfield style accounts do not exist in this database.

A page fails and you see nothing useful in the browser
   Look in the PowerShell window running the web server. Every error
   and PHP warning is printed there.

A page says you do not have permission
   You are signed in as the wrong role. The admin pages need an Admin
   account.
